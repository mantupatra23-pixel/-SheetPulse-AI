SheetPulse AI Documentation

SheetPulse AI brings autonomous neural models directly inside Google Sheets cell formulas. Extract data points, clean unstructured strings, categorize feedback, and scrape websites without writing custom scripts.

  • • Sub-Second Execution: Multi-engine cloud routing ensures cells evaluate in <0.8s.

  • • Zero-Downtime Fallback: Automatic cascade failover across high-throughput inference backends.
Quick Setup

2-Minute Google Sheets Installation

1. Open Apps Script Editor

In your Google Sheet, navigate to Extensions > Apps Script.

2. Paste the Client Snippet

Erase any placeholder code and paste our standard integration script from the landing page.

3. Save and Start Using Formulas

Click 💾 Save. Return to your spreadsheet and type =AI_CLEAN(A2).

API Reference

Complete AI Formulas Catalog

=SHEETPULSE(cell, instruction)

General AI

Executes natural language prompts directly on cell contents. Used for taglines, copy variations, and custom data workflows.

Syntax: =SHEETPULSE(A2, "Write a 4-word punchline")

SheetPulse AIWrite 4-word SaaS hookUnlock Data's Full Potential

=AI_CLEAN(cell)

Data Sanitizer

Fixes inconsistent casing, trims broken whitespace, standardizes email formats, and cleans messy lead lists.

Syntax: =AI_CLEAN(A2)
Input (A2)Cleaned Output
mAntU pAtRA @ GMAIL . COM mantupatra@gmail.com

=AI_EXTRACT(cell, target_entity)

Entity Parser

Extracts specific entities (emails, phone numbers, prices, names, dates) using an automated fast-regex parser followed by neural fallback.

Syntax: =AI_EXTRACT(A2, "CEO email address")

=AI_CLASSIFY(cell, categories)

Classification

Assigns text to strictly one category from your comma-separated tag list. Ideal for review sentiment, ticket triage, and expense categorisation.

Syntax: =AI_CLASSIFY(A2, "Complaint, Feedback, Urgent")

=AI_FIX(broken_formula, goal)

Formula Fixer

Detects syntax, index offset, or range errors in Google Sheets formulas (e.g. broken VLOOKUP, INDEX/MATCH) and returns the corrected working formula.

Syntax: =AI_FIX("=VLOOKUP(A2, B:C, 3, FALSE)", "Fix 2-column lookup")

=AI_SCRAPE(url, question)

Live Scraper

Fetches live web content directly from a target URL and extracts the answer to your query in a single formula step.

Syntax: =AI_SCRAPE("https://stripe.com", "Extract pricing headline")
Troubleshooting

Error Resolutions & Best Practices

Error: 401 Unauthorized / Invalid Key

Your SHEETPULSE_API_KEY is invalid or empty. Generate a fresh key from the dashboard.

Error: 402 Credits Exhausted

You reached your monthly credit limit. Top-up credits or switch to the Free BYOK plan.

⚡ Pro Tip: Prevent Formula Recalculation

To freeze output values and prevent Google Sheets from re-calculating formulas on every edit: Select the output column → Right Click → Paste Special > Values Only.
