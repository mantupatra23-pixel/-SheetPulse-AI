Documentation / Overview

SheetPulse AI Documentation

SheetPulse AI integrates autonomous neural models directly into Google Sheets custom formulas. You can extract entities, clean unstructured columns, classify support tickets, and scrape live URLs without writing complex scripts or switching browser tabs.

⚡ Core Architecture Highlights

  • • Sub-Second Execution: Multi-engine cloud cluster ensures response times under 0.8s per cell.
  • • In-Memory Cache: Identical requests evaluate in 0.001s without consuming API credits.
  • • Enterprise Fallback: Zero-downtime automated cascade across multiple AI backends.

📦 2-Minute Google Sheets Installation

Follow these 3 steps to activate SheetPulse AI inside any Google Spreadsheet:

  1. Step 1: Open Apps Script
    In your Google Sheet, click Extensions > Apps Script from the top navigation bar.
  2. Step 2: Paste the Client Snippet
    Delete any existing code in the editor and paste the one-click client code from the Integrations section.
  3. Step 3: Save and Run
    Click the 💾 Save icon. Return to your spreadsheet and type any formula like =AI_CLEAN(A2).
Function Reference

Complete AI Formulas Catalog

=SHEETPULSE(cell, instruction)

General AI

Executes custom natural language instructions on cell data. Ideal for generating ad copy, summaries, hooks, or customized translations.

Syntax: =SHEETPULSE(A2, "Write a 4-word punchy tagline")
Input (A2)InstructionResult
SheetPulse AIWrite a 4-word punchlineUnlock Data's Full Potential

=AI_CLEAN(cell)

Data Sanitizer

Standardizes irregular casing, trims excessive whitespace, fixes corrupted phone/email formats, and removes noisy artifacts.

Syntax: =AI_CLEAN(A2)
Input (A2)Cleaned Result
mAntU pAtRA @ GMAIL . COM mantupatra@gmail.com

=AI_EXTRACT(cell, target_entity)

Entity Parser

Extracts specific data points (emails, phone numbers, prices, names, dates) using an automated fast-regex bypass followed by neural inference.

Syntax: =AI_EXTRACT(A2, "email address")

=AI_CLASSIFY(cell, categories)

Classification

Assigns text to exactly one category from your provided comma-separated list. Ideal for review sentiment, ticket triage, and expense categorisation.

Syntax: =AI_CLASSIFY(A2, "Complaint, Feedback, Urgent")

=AI_FIX(broken_formula, goal)

Formula Repair

Detects syntax, index offset, or range errors in Google Sheets formulas (e.g. broken VLOOKUP, INDEX/MATCH) and returns the corrected working formula.

Syntax: =AI_FIX("=VLOOKUP(A2, B:C, 3, FALSE)", "Fix 2-column lookup")

=AI_SCRAPE(url, question)

Live Scraper

Fetches live web content directly from a target URL and extracts the answer to your question in a single formula step.

Syntax: =AI_SCRAPE(A2, "Extract headline title")

⚠️ Troubleshooting & Best Practices

Error: 401 Unauthorized / Invalid Key

Your SHEETPULSE_API_KEY is either missing or expired. Generate a fresh key from the landing page dashboard.

Error: 402 Credits Exhausted

You have reached the free credit tier limit. Top-up credits or switch to Hosted Pro / BYOK mode.

Preventing Formula Recalculation

To freeze calculated values and prevent Google Sheets from re-triggering formulas on every sheet edit: Copy the calculated column → Right Click → Paste Special > Values Only.
