Quick Setup

2-Minute Installation Guide

1. Open Apps Script Editor

In your Google Sheet, click Extensions > Apps Script.

2. Paste the Client Snippet

Paste our standard integration code from the landing page into the editor.

3. Save and Run Formulas

Click 💾 Save. You can now write =AI_CLEAN(A2) in any cell.

Formulas

Complete Formulas Reference

=SHEETPULSE(cell, prompt)

General AI

Executes custom natural language instructions on cell data.

=SHEETPULSE(A2, "Write 4-word hook")
InputInstructionOutput
SheetPulse AIWrite 4-word hookUnlock Data's Full Potential

=AI_CLEAN(cell)

Sanitizer

Standardizes casing, trims broken whitespace, and formats messy data.

=AI_CLEAN(A2)

=AI_EXTRACT(cell, target)

Extractor

Extracts specific entities (emails, phone numbers, prices) with regex acceleration.

=AI_EXTRACT(A2, "CEO email address")

=AI_CLASSIFY(cell, tags)

Classifier

Assigns text strictly into one tag from your comma-separated list.

=AI_CLASSIFY(A2, "Complaint, Bug, Refund")

=AI_FIX(broken_formula, goal)

Repair

Analyzes and fixes broken Google Sheets formulas.

=AI_FIX("=VLOOKUP(A2, B:C, 3, FALSE)", "Fix 2-column lookup")

=AI_SCRAPE(url, question)

Web Scraper

Scrapes target website URL and extracts the required answer.

=AI_SCRAPE("https://stripe.com", "Extract pricing headline")
